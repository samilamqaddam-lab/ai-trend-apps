## 💡 The App

This web app helps users create optimized prompts for generating their AI caricatures. Instead of struggling to write the perfect prompt, users can:

1. Fill out a simple form with their info (name, occupation, traits, hobbies)
2. Choose from various caricature styles (Pixar, Comic, Chibi, etc.)
3. Get a perfectly formatted prompt to copy and paste into ChatGPT
4. Generate their viral caricature in seconds

## 🎨 Features

- **6 Style Options:** Pixar, Classic Cartoon, Comic Book, Chibi, Realistic, Minimalist
- **Personality Traits:** Select multiple traits to personalize the character
- **Hobby Integration:** Automatically incorporate interests into visual elements
- **Copy to Clipboard:** One-click copy of the generated prompt
- **Mobile Friendly:** Responsive design works on all devices
- **Beautiful UI:** Gradient background with smooth animations

## 🚀 How to Use

1. Open `index.html` in any modern web browser
2. Fill out the form with your details
3. Click "Generate Prompt"
4. Copy the generated prompt
5. Paste into ChatGPT (GPT-4 with DALL-E recommended)
6. Share your caricature on social media!
