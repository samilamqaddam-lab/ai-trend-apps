## What This App Does

Interactive 5-step workflow to plan your AI agent adoption:

1. **Role selector** — Choose from 8 job archetypes (dev, marketer, analyst, PM, writer, designer, sales, ops)
2. **Task inventory** — See all your regular tasks with AI delegability scores (0–100%)
3. **AWU Calculator** — Calculates your Agent Work Units score based on your delegation choices
4. **Adoption Journey** — Visual timeline showing where you are on the augmentation path
5. **Agent Stack** — Personalized recommendations for which AI tools to deploy

## Key Features

- 72 pre-mapped tasks across 8 roles with AI readiness scores
- Live AWU calculation with context ("≈ 2-3 freelancer equivalents")
- Toggle delegation on/off per task and see immediate impact
- Journey timeline from "Individual Contributor" → "Agent Supervisor"
- Personalized agent stack recommendations with specific tools
